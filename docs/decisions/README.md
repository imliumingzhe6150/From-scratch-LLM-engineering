# Architecture Decision Records

These short records preserve why an implementation choice was made. Add a new
numbered file when a decision has alternatives or consequences that may matter
later; routine code changes belong in the development log instead.

Recommended structure:

```markdown
# NNN: Decision title

- Status: Accepted, Superseded, or Proposed
- Date: YYYY-MM-DD

## Context
## Decision
## Rationale
## Consequences
## Evidence
```
