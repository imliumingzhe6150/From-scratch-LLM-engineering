## Concepts Clarified

- `nn.Parameter` registers a Tensor as learnable model state.
- `state_dict` maps hierarchical parameter names such as `w1.weight` to their
  values; tests load fixed weights so implementations can be compared fairly.
- Mathematical column-vector notation `Wx` corresponds to `x @ W.T` for the
  batched row-vector layout used by PyTorch.
- RMSNorm operates independently over the final feature dimension of every
  token and does not mix information across sequence positions.
- Each `Linear` object contains a weight matrix and the transformation using it;
  it is not merely another name for a Tensor.
