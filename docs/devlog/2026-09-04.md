## Concepts Clarified

- RoPE changes query and key vectors through 2D rotations rather than adding a
  position vector to token embeddings.
- Feature pair `i` rotates by `position * theta ** (-2i / d_k)`, so later pairs
  rotate more slowly.
- Applying rotations at positions `m` and `n` makes a query-key dot product
  depend on the relative displacement `n - m`.
- A rotation preserves each query/key vector's Euclidean norm.
- Cached trigonometric tables are fixed derived state, so module buffers are a
  better fit than parameters.
