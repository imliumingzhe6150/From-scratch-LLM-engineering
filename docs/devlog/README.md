# Development Log

Development logs are chronological records of what changed during a session.
They are not the source of truth for current status; use `PROJECT_STATUS.md` for
that purpose.

Use filenames in `YYYY-MM-DD.md` format. Each entry should record:

- the session goal;
- implementation changes;
- concepts clarified;
- commands/tests run and their exact outcomes;
- unresolved questions;
- the next concrete task.

The earlier `docs/DAILY_SUMMARY_2026-08-30.md` is retained as a historical log
created before this directory structure was introduced.
