## Autoregressive Text Generation

- Added temperature scaling and exact nucleus sampling. Top-p filtering retains
  the first sorted token that crosses the cumulative-probability threshold,
  removes lower-probability choices, and renormalizes the result.
- Added multinomial next-token sampling and deterministic greedy decoding for
  temperature zero.
- Added a single-prompt autoregressive loop with maximum-token and EOS stopping,
  read-only inference, training/evaluation mode restoration, and a sliding
  context window after the sequence exceeds the model limit.
- Added a command-line entry point that loads the BPE tokenizer and model
  checkpoint, accepts a user prompt, and exposes temperature, top-p, seed, and
  maximum-generation settings.
- Documented a complete TinyStories generation command in the README.
